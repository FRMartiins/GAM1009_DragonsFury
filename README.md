# Dragon's Fury

## Project Overview
Dragon's Fury is a top-down shoot 'em up game developed in Unreal Engine 5 for the GAM1009 assessment at AIT.

The player controls a dragon that shoots fireballs at incoming Viking enemies while avoiding enemy attacks.

## Gameplay Features
- Mouse-controlled dragon movement
- Fireball shooting mechanic
- Viking enemies with animations
- Continuous enemy spawning
- Enemy axe projectiles
- Collision detection and damage system
- Score and health display
- Visual effects and sound effects
- Game Over system

## Controls
- Mouse Movement: Move the dragon
- Mouse Button: Fire projectiles

## Technologies
- Unreal Engine 5
- Blueprint Visual Scripting
- Niagara Visual Effects

## How to Open the Project
1. Download or clone the repository.
2. Install the compatible version of Unreal Engine 5.
3. Open GAM1009_Shootemup.uproject.
4. Open the LV_MainGame level.
5. Press Play to start the game.
